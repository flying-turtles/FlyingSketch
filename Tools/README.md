# Tools

## Bundled part catalog (`App/Catalog`)

`App/Catalog` is generated. Do not edit it by hand. To regenerate it (macOS):

```sh
Tools/fetch-parts.sh                     # pinned fritzing-parts + Adafruit Fritzing-Library into Vendor/ (gitignored)
python3 Tools/custom-parts/generate.py   # only when custom parts or their pin tables changed
cd Tools/CatalogBuilder && swift run catalog-builder ../catalog-manifest.json ../../Vendor ../custom-parts ../../App/Catalog
```

Then run the package tests (`CatalogTests` check the generated files) and commit `App/Catalog` together with its inputs.

- `catalog-manifest.json`: one entry per part, `{ "source": "fritzing-parts" | "adafruit" | "custom", "fzp": "<path>", "id": "<catalog id>" }`.
  `fzp` is relative to `Vendor/fritzing-parts`, `Vendor/Fritzing-Library` (an `.fzpz`) or `Tools/custom-parts`.
- `catalog-builder` fails with a non-zero exit and lists every part that does not import. The previous catalog stays
  unchanged in that case. Output is deterministic: sorted keys, coordinates rounded to 1e-6 mm, and graphics copied byte for byte.
- `ATTRIBUTION.md` lists source, path, commit, `.fzp` authors and license for every part. Fritzing parts are CC-BY-SA 3.0.

## Custom parts (`custom-parts/`)

These are our own parts (MIT, Lars Grof), generated by `custom-parts/generate.py`:

- `esp32-s3-devkitc-1`, `esp32-c3-devkitm-1`. Header pin names, order and types come from the pin tables in
  `Packages/FlyingSketchKit/Tests/PartsKitTests/Fixtures/esp32{s3-devkitc1,c3-devkitm1}-pins.json`. Those tables were
  transcribed from the Espressif user guides, and each file records its source URL:
  - https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32s3/esp32-s3-devkitc-1/user_guide_v1.1.html
  - https://docs.espressif.com/projects/esp-dev-kits/en/latest/esp32c3/esp32-c3-devkitm-1/user_guide.html

  Board geometry comes from the Espressif dimension drawings (DXF). Their URLs are in `generate.py`.
- `pushbutton-6mm`: a 6 mm tactile switch with its legs exactly on the 5.08 x 7.62 mm breadboard grid. Pin names and buses match
  Fritzing's core pushbutton.

Pin roles are set explicitly with `flyingsketch:role="power|ground|digital|analog|i2cSDA|i2cSCL|spi|uart|other"` on
`<connector>` (namespace `https://github.com/flying-turtles/FlyingSketch`). An explicit role overrides the name heuristic.
