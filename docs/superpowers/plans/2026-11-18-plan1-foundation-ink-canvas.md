# FlyingSketch Plan 1 — Foundation: Documents + Infinite Ink Canvas

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working iPad document app: create/open `.flysketch` files, draw with Pencil on an infinite pan/zoom canvas, erase, lasso-select, move/delete/duplicate/copy-paste, add shapes, text and images, with undo/redo and autosave.

**Architecture:** One local Swift package `FlyingSketchKit` with three targets: `SketchCore` (pure model, geometry, commands, file format — no UIKit), `InkEngine` (touch samples → stroke geometry, ported from the spike — no UIKit), `CanvasUI` (UIKit canvas view, rendering with Core Animation, tools). A thin SwiftUI app target hosts it via `DocumentGroup`.

**Tech Stack:** Swift 6, SwiftUI, UIKit, Core Animation, Swift Testing, xcodegen.

**Spec:** `docs/superpowers/specs/2026-11-18-flyingsketch-v1-design.md`

### Roadmap (separate plans, written after this one ships)

## Global Constraints

- Minimum iPadOS 26; device family iPad only (`TARGETED_DEVICE_FAMILY: "2"`).
- Swift 6 language mode, strict concurrency; `SWIFT_DEFAULT_ACTOR_ISOLATION: MainActor` for app and `CanvasUI`; `SketchCore`/`InkEngine` types are `Sendable` value types.
- Project generated by xcodegen from `project.yml`; `*.xcodeproj` is gitignored.
- Signing: `DEVELOPMENT_TEAM: WDJPX25GFC`, bundle id `com.flyingturtle.flyingsketch`.
- No GPL dependencies. No third-party dependencies at all in Plan 1.
- No `.metal` files (Metal toolchain not installed).
- License: MIT.
- World units: millimetres, `Double`. Canvas unbounded.
- Zoom range: 0.05 … 32 (5 %–3200 %). Base mapping at zoom 1: 1 mm = `pointsPerMillimetre` = 160/25.4 pt (≈ 6.3 pt, real size on a 160 pt/inch basis).
- Ink smoothing default: off.
- Document type: package `.flysketch` = directory with `document.json` + `assets/`; JSON has `formatVersion` (Plan 1 writes `1`).
- Gestures: Pencil draws with active tool; one finger selects/moves; two fingers pan/pinch; two-finger tap = undo; three-finger tap = redo; Pencil double-tap = toggle eraser.
- Performance target on iPad8,11: ≥ 60 fps pan/zoom with 5 000 ink strokes; live-stroke latency equal to the spike's Core Animation pane.
- Test command (all package tests, iPad simulator):
  `cd Packages/FlyingSketchKit && xcodebuild test -scheme FlyingSketchKit-Package -destination 'platform=iOS Simulator,id=08D1B7B4-263D-4479-8F34-C24730978306' -quiet`
  Single test: append `-only-testing:<Target>Tests/<Suite>/<test>`.

## Review Focus

1. **Pencil tap (single sample)** must produce a visible dot that saves, reloads, is hit by the eraser and lasso. → tests in Task 5 (`singleSampleProducesDot`) and Task 4 (`hitTestsDotStroke`).
2. **Stroke interrupted** (touch cancelled by palm, system gesture, incoming call) must not leave a partial stroke or an undo entry. → test in Task 7 (`cancelledStrokeCommitsNothing`).
3. **Document written by a newer app version** (`formatVersion` > 1) or corrupt JSON must fail to open with an error, not crash or open empty and overwrite. → test in Task 3 (`rejectsNewerFormatVersion`, `rejectsCorruptJSON`).
4. **Zoom extremes**: pinch beyond limits clamps; ink drawn at 5 % and 3200 % keeps its mm width relative to the world. → tests in Task 2 (`clampsZoom`) and Task 7 (`strokeWidthIsWorldUnits`).
5. **Large documents**: only objects in the visible rect get layers. → test in Task 6 (`createsLayersOnlyForVisibleObjects`).
